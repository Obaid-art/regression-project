# Machine Learning: Regression — the project (90 minutes)

[![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/Obaid-art/regression-project/blob/main/project.ipynb)

Prof. Ali Elkamel · Khalifa University · Department of Chemical Engineering

One notebook, nine datasets, six guided steps, no coding. Each group picks its dataset in the first dropdown, cleans the data, splits it, fits a line, trains a small neural network, decides whether the network was needed, and presses one button that writes the group's report and slides.

## How to open it
1. Click the **Open in Colab** badge above (any Google account works).
2. Run the first cell once. The nine datasets are inside the notebook; nothing to upload.
3. Pick your group in Step 1 and run the steps top to bottom.
4. Step 6 downloads your report (HTML), your slides (PPTX), the figures and a results file.

It also runs in Jupyter: download `project.ipynb` and open it with Jupyter Notebook or JupyterLab (needs `ipywidgets`, `numpy`, `matplotlib`, `python-pptx`; the first cell installs what is missing).
